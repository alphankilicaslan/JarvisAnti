# JarvisAnti

**JarvisAnti**, Google Antigravity için geliştirilmiş 7/24 çalışan, tamamen çevrimdışı (ONNX) Siri tarzı ses tonu ve uyandırma kelimesi algılayıcısıdır.

## Özellikler
- **Nöral Uyandırma Motoru (Çevrimdışı ONNX)**: Silero VAD v5 + Sherpa-ONNX KWS + openWakeWord + konuşmacı biyometrik doğrulama (DTW + Resemblyzer ONNX).
- **Çift El Alkışı (Double Clap) ile Uyandırma**: İsteğe bağlı hassasiyet ayarlı alkış algılayıcı.
- **Siri Küresi Animasyonu & Sistem Tepsisi**: Hafif, modern karanlık tema arayüzü, canlı ses tonu test ölçeri ve dahili log görüntüleyici.
- **AlpTogether Ekosistemi**: Merkezi bulut whitelist, HWID doğrulama ve otomatik güncelleme kontrolü.
- **Tamamen Taşınabilir & Dinamik Yollar**: Tek dosya `JarvisAnti.exe`, tüm kullanıcı verileri `%LOCALAPPDATA%\JarvisAnti` altında saklanır.
